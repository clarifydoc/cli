# Go plugin

Reads `.go` files through a regex `RegexLangSpec` ([index.ts](index.ts)) with an ANTLR front end (`meta.antlr`) supplying functions and calls; a file the parser reports syntax errors for keeps the regex reading. Parser internals (decision settling, the grammar) are in [parsers/AGENTS.md](../../../parsers/AGENTS.md). LSP: gopls (Docker image under `docker/go/`; `indexDelayMs` 5 s). Control flow is the approximate regex tier (`meta.regexControlFlow`).

## Rules across files

- Register functions nobody calls: a route registered on a router parameter (`func registerOld(g *gin.RouterGroup)`) is dropped when no `router-call` reaches the function, no call in the scan names it and no file uses its name as a value (`registerDocs = api.GetDocs`, a table of them: the per-file `func-ref` fact, `goFunctionValueNames`) — and the function is unexported, or exported in a package some scanned file imports. An exported function in a package nothing scanned imports is a library's entry point and keeps its routes at the path it knows. A function only a dead function hands its router to is dropped too (`uncalledIsDead` in [router-fn-resolver.ts](router-fn-resolver.ts), the rule in [../shared/router-functions.ts](../shared/router-functions.ts)). Ktor and the JS/Python mount passes do not use the rule yet.
- `directoryNamesShared` makes every file of a directory one package for names (package variables, bare calls, functions); `typesSpanFiles`: methods beside their struct in other files make one type (`ClassRef.parts`), and a package-qualified type (`models.Club`) states nothing for member effects. `ClassInfo.kind: "interface"` with `structural: true` marks Go interfaces.
- Unique-global-leaf evidence is the files of every package any non-test file of the caller's package imports; a receiver that is a package no directory holds (`strings.Cut`) is vetoed.
- `valuePathsNameNoType`: `a.b.C.m(` never names a type, so a `receiverCut` name (`s.Controller.Delete(` read as `Controller.Delete`) is refused by the ClassName.method guess, and a held noise member (`c.Status.String(`) called through a path from a typed head is restored (`restoreTypedReceiverCalls`). Both front ends name a path from a local by its whole path (`c.Status.String`), so the linker types the local (`localTypes`) and follows the fields. A `receiverCut` call has no head the caller binds: Strategy 2, `chainReceiverType`, `receiverTypeRefuses` and the name guess's declared type all leave it alone.
- A typed chain follows promoted fields and embedded interfaces; multi-value returns (`c, err := repo.Find(1)`) type the first result by the declared results; a `from` may be a call chain, and `range` over a chain of calls and fields types the loop variable by the element. Alias `q := p` / `&p` is `LocalType.aliasOf`.
- Struct literals construct: Go and Rust call `withStructLiteralCalls` ([../shared/struct-literals.ts](../shared/struct-literals.ts)) from `postProcessFunctions`/`postProcessClasses`: each literal in expression position (`Club{…}`, `models.Club`) becomes a call with `CallInfo.construction: "literal"`, linking `instantiates` to the struct itself (`constructionLink`, never a `New…` function); never for a block opener (`if x {`, `-> Club {`), a collection literal (`[]Club{}`) or a pattern.
- Package variables (`var store = NewStore()`, `var cache Cache`) are `FileAnalysis.moduleBindings`: `type` as written, or `from` (the initializing call chain) when only a call states it; core types a `from` binding by the callee's declared result. Locals, parameters and any name the body binds (`FunctionInfo.boundNames`) shadow it; a bare name nothing local takes reads the file's `moduleBindings`, then its sibling files' and their functions (`packageScoped` language).
- Handlers: a handler built for a type it binds the request into carries `RouteInfo.handlerTypes`; the type's tagged fields are `PropertyInfo.boundFrom` (Huma `input *ClubInput` with `path:"club"` tags), from which parameter-column origins flow through `receiver-field` / `param-field` origins; a bound struct's non-numeric fields are taint sources.
- Thrift: generated stubs (Go `NewClubServiceClientFactory`) ride the gRPC hooks (`grpcStubService`/`grpcServiceOf`); a stub TYPE (`ClubServiceClient`) counts only in a file importing the Thrift runtime or a package the project generated from a `.thrift` (a `gen-go/` path, or a package declaring `XClient` beside `XProcessor` — `core/grpc-clients.ts` hands the stub hook every analyzed file, and `firstStub` prefers a certain answer). Handlers the generated code does not name — `NewClubServiceProcessor(&clubHandler{})` — are `thrift-handler` route facts joined by the `thrift-handlers` resolver.
- Routes and tests: middleware registrations (`Group("/x", auth.Require(db))`) become `RouteInfo.middlewareCalls`; `go test -run` is the test command; a bare call of an unbound name states an `invoke` on `{ name, package: true }` (value flow).
- Messaging: Go `paho` MQTT is `topicSyntax: "mqtt"`; `SubscribeMultiple(map…)` gives one row per topic; a topic held in an exported `pkg.Name` is a `targetRef` row; Dapr pub/sub is read when the file imports the SDK. Go cover profiles map to `testCoverage`.
- Param columns: an object handed to a generic handler that calls a method on it (`DoUpdate(ctx, obj CObject, a)` → `obj.Update`) goes on through the call site's `interface-redirect` link to that type's method. A local declared by type and assigned on each arm (`var api Api; if … { api = a() } else { api = b() }`) needs no `choice`. A field receiver typed `*http.Error` keeps its qualifier through `writtenTypeName`; it binds a project class only where the project backs it (`qualifierBacksClass`).
