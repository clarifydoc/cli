# Python plugin

Reads `.py` and Jupyter `.ipynb` files with tree-sitter (a flat-tree language, so the copy is byte-identical to the real tree); Flask, FastAPI, Django/DRF, Celery, SQLAlchemy/SQLModel/Alembic, aiosql, GraphQL and pytest facts hang off the same `FileAnalysis`. A file's header comment holds its mechanism; this page is the map and the rules that span files.

## Rules a change must respect

- `Python` is in `FLAT_TREE_LANGUAGES`. A Python `Protocol` is `ClassInfo.kind: "interface"` with `structural: true`. Extension-less scripts whose `#!` names a Python interpreter are Python files (manifest `shebangInterpreter`).
- Notebooks are read through `preprocess` ([notebook.ts](notebook.ts)): facts carry lines of the CONCATENATED code, never the notebook JSON.
- `extractPythonDecorators` reads the `decorator` children of `decorated_definition`; the call walk's read set adds `decorator`, and `collectExtraCalls` reads decorators as calls. `typeNamedByReceiver` converts snake to Pascal (`match_report` → `MatchReport`). `transparentTypeWrappers` lists `Annotated`.
- Security: the assignment rule is `raw` because `securityPreprocess` blanks strings; a finding whose value is prose or a namespaced name (`isKeyShapedValue`) is dropped; bandit's `# noqa: S105`/`S106`/`S107` silence hardcoded-secret only (`suppressionOf`). The known-package table classifies `shutil`/`zipfile`/`tarfile` as filesystem and `smtplib` as email (never `os`/`pathlib`); it never classifies a Python import (`standardImport` does).
- Performance: [python-tokenizer.ts](python-tokenizer.ts) backs the type-reference walkers (`stripPythonNonCode` scans char codes and copies by `slice`); a whole-text gate asked per call site is computed once per file (`managerAssigned`); a per-argument walk of the enclosing function (`assignsTo`) is one walk per function, kept per tree in a `WeakMap`.
- Imports: `ImportInfo.aliases` (local → exported) is filled for `from x import a as b` and the import index asks Python's own resolver for the exported name (`from app.api import api as articles` names module `api`). A dotted import resolves by the package its directories spell, never by the leaf file name; `standardImport` and a manifest-declared package keep an external import off a project namesake (`azure.storage.blob` → `azure-storage-blob`). An import inside a function binds in that function only (`ImportInfo.scope`, decorators included; `classifyCalls` gets the unscoped imports plus the scoped ones holding the callable). Star imports are followed through the modules they name (three hops, one definition, `starChainDefinition`); a package `__init__`'s `from .impl import X` is followed to the definition, unique-or-nothing; a module-level alias (`s = attrs`, `FileAnalysis.nameAliases`) leads to the function it names. A script RUN rather than loaded (`subprocess.run`, `fork`) carries `executes: true` and shares nothing. `directoryIndexStems` is `__init__`: a URL helper called through a module binding (`urls.club_url(id)`) is looked up in the imported module's file only where the head is the module itself, never where it is a named export. A local typed through an imported module (`m.Club`) takes the class that module's file declares (`moduleQualifiedType`). `multipleInheritance` makes member lookup follow C3 order.
- `save` is a write on an instance or an ORM receiver, not on a module bound by a plain `import x` (`savesThroughLibraryModule`, [data-sources.ts](data-sources.ts)).
- Fact maps (`fieldValues`, `moduleValues`) are read by own property only (`ownValue`).
- Plugins keep no module state; a client base's overriding variables are `ConfigEntry.envNames` (`meta.serviceConfig`).

## Files

Typing and value flow
- [di.ts](di.ts) — instance attributes, typed locals, aliases, narrowing (`for i, (a, b) in enumerate(pairs)` types the element), injection tokens, container registrations; [returned-modules.ts](returned-modules.ts) — a local bound to a module (`FunctionInfo.returnsModule`, `localTypes[].module` from `m = importlib.import_module("league.club")`); [value-flow.ts](value-flow.ts) — callable value flow; [member-effects.ts](member-effects.ts) — `fieldWrites`/`throws`; [type-aliases.ts](type-aliases.ts), [type-references.ts](type-references.ts), [module-values.ts](module-values.ts), [module-names.ts](module-names.ts), [module-resolver.ts](module-resolver.ts), [standard-library.ts](standard-library.ts), [call-hooks.ts](call-hooks.ts), [functions-classes.ts](functions-classes.ts), [imports-exports.ts](imports-exports.ts).
- [arg-origins.ts](arg-origins.ts) states `CallInfo.argOrigins`; [request-access.ts](request-access.ts) `FunctionInfo.requestAccess`; [request-schema.ts](request-schema.ts) the `requestSchema` hooks that map a body-bound class to JSON; [response-reads.ts](response-reads.ts), [file-path-reads.ts](file-path-reads.ts) (`open(…)`, `Path(…).read_text()`, `os.path.join` with literal parts only).

Routes and frameworks
- [routes.ts](routes.ts) — Flask and FastAPI decorators and mounts, Django guard decorators. A FastAPI `include_router(x, prefix=…)` of a router the same file declares (`x = APIRouter()`) prefixes only the routes decorated on `x` (`applyLocalIncludes`); an imported router goes through the cross-file mount. [settings-prefix.ts](settings-prefix.ts) — `include_router(…, prefix=settings.x)` takes the literal default of the class a holder (`settings = Settings()`) instantiates; [fastapi-guards.ts](fastapi-guards.ts) — `dependencies=[Depends(x)]` as `middlewareCalls`/`inheritedMiddleware`; a dependency is a guard only when its name says it checks the caller.
- [django/](django/) — urlconfs and DRF routers are per-file `routeFacts` joined by the `django-urlconf` resolver ([resolver.ts](django/resolver.ts)) through `include("mod")` and unresolved `allauth` includes (handlers `allauth.account.views.<view>`); a row the resolver moves onto its view keeps the urlconf line as `RouteInfo.registeredAt` (as Rails rows keep `config/routes.rb`), so rename plans edit it and the urlconf reads as the app's routing layer; [viewset-actions.ts](django/viewset-actions.ts) (`drf-action` dispatch, following `super().<action>()` into the hooks), [serializer-dispatch.ts](django/serializer-dispatch.ts) (`drf-serializer`, `CallInfo.key` `drf-serializer:create|update`), [drf.ts](django/drf.ts) shared rules, [library-writes.ts](django/library-writes.ts) (DRF generic views and `ModelSerializer.save()` and django-allauth views write their model; `DataSourceInfo.authUser`), [template-links.ts](django/template-links.ts), [test-setup.ts](django/test-setup.ts) (`testSetupRuns`: Django migrations and `AppConfig.ready()` under pytest-django). `url_for`/`reverse` and templates' `{% url 'clubs:detail' %}` link by route name.
- [graphql.ts](graphql.ts), [pytest-fixtures.ts](pytest-fixtures.ts) — a test's or fixture's parameter is injected by pytest and never an `invoke` target.
- [http-clients.ts](http-clients.ts) — `httpx`/`aiohttp`/`BaseUrlSession` `httpClientRegistrations` (a name bound twice registers nothing; the api-call row names its receiver as `client`); labelled fixture `test-fixtures/sample-microservices` (an `archive` decoy). A Thrift handler `ClubService.Processor(handler)` is a `thrift-handler` route fact; Dapr pub/sub, pika/AMQP, Kafka and Celery tasks are queue nodes of the data-access graph, and module-level code attributes to the file's `<setup>`.

Data
- [entities.ts](entities.ts) — SQLAlchemy/SQLModel/Django/Pony entities and relations (a `@declared_attr` with `return relationship(…)` or `return orm.relationship(…)` is a relation); [alembic-schema.ts](alembic-schema.ts) — `op.create_table(…, schema="league")` gives `schemaOps` and schema-qualified tables; [data-sources.ts](data-sources.ts), [data-mutations.ts](data-mutations.ts), [aiosql.ts](aiosql.ts) (named queries: an argument given by name lands on the callee's parameter of that name and is the only kind followed through a dispatch link), [repository-access.test.ts](repository-access.test.ts) (the shared `attributeRepositoryAccesses` knobs), [migration-files.ts](migration-files.ts).

Packages, reachability, tests
- [package-manifests.ts](package-manifests.ts) — a `requirements.txt` is read through `readTextFile` (UTF-16 by its mark). [reachability.ts](reachability.ts) — bespoke: imports + `__init__` chains, `__main__`, `module:`/`file:` references, server commands; libraries are not judged. [taint.ts](taint.ts) — the `ast.taint` hook of `handlerTaint`. [test-command.ts](test-command.ts) (pytest node ids), [project-commands.ts](project-commands.ts).

## How core passes read it

- A loop over a literal or module-level constant of classes is a row per listed class; `model_count(model=Club)` is reported as `model=Club` after the positional arguments.
- Layers: `routers/api.py` mounting `routers/clubs/` is the routers folder using its parts.
- `FileAnalysis.moduleNames` lets `impact` charge only the importers that read an edited constant; a `from .x import *` forwarder is charged only when the change takes a name away.
