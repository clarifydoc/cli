# C plugin

Reads C (`.c`) through regex patterns with an ANTLR front end (`antlr.ts`, `meta.antlr`); a file with syntax errors keeps the regex reading, and `--feature no-antlr` switches back to it. C is a `cfam` plugin: includes, headers, macros as facts, struct ops tables, callable fields, value flow, `p->m()` naming, vendored banners, reachability, control flow, CMake test commands and the project marker are shared with C++ and described once in [../cpp/AGENTS.md](../cpp/AGENTS.md) (macro links: [macros](../cpp/AGENTS.md#macros)). `.h` has one owner (C++); a project with `.c` and no C++ source reads its headers C-first (variant `c-first`, in that file). Parser internals — the two-pass reading, the type-name pass, retyped macros, settled decisions — are in [../../../parsers/AGENTS.md](../../../parsers/AGENTS.md).

## Files

- [index.ts](index.ts) — the spec: what C states (function-pointer `invoke`s with `ifFnType`, `functionTypeAliases`, header-bound imports).
- [antlr.ts](antlr.ts) — the ANTLR reader; unexpanded macros are grammar rules and a file that does not parse is read again with each conditional's first branch ([../shared/preprocessor-branches.ts](../shared/preprocessor-branches.ts), [../shared/token-calls.ts](../shared/token-calls.ts), shared with C++). When that reading stops too, `ParsedStructure.errorLine` (the token the parser stopped at, C only) names the line, and the innermost conditionals around it that have no `#else` are left out one at a time (`readWithoutLoneBody`, at most two, calls counted where they fall): a GNU nested function (`auto inline int f(x) int x; { … }`, which the grammar has no rule for) inside one `#ifdef` no longer refuses the file. A conditional with an `#else` is never dropped, and a reader that gives no `errorLine` (C++) skips the attempt.
- [rewrites.ts](rewrites.ts), [manifest.ts](manifest.ts), [meta.ts](meta.ts) — source rewrites for the reader, static tier, wiring.
